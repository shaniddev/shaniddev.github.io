# shanid.github.io

Personal portfolio of Shanid — Senior Software Engineer (Laravel, PHP, Python/Django, APIs), Doha, Qatar.

Live: https://shanid.github.io/

Plain static site — no build step.

- `index.html` — the page
- `assets/css/site.css` — shared styles (most styling is inline)
- `assets/js/main.js` — ID-card flip, case-study tabs, AI question chips, copy email, nav highlight
- `assets/logos/` — project logos
- `assets/icons/` — skill logos (from Simple Icons, CC0)
- `assets/shanid-cv.pdf` — CV for the View / Download buttons

To deploy: push to the `main` branch, then in GitHub → Settings → Pages choose "Deploy from a branch", branch `main`, folder `/ (root)`.
